# Multiple Myeloma (MM) — ICD-10, HCPCS/CPT and Drug Code Reference


## 10. ICD-10, HCPCS/CPT and Drug Code Reference


### 10.1 ICD/10 Codes

#### 10.1.1 Core MM ICD-10-CM Codes

| ICD-10-CM Code | Description | Notes |
|---|---|---|
| C90.0 | Multiple myeloma | Non-billable category; use specific subcodes. [ICD10Data C90.0] |
| C90.00 | Multiple myeloma not having achieved remission | Active disease / not in remission. [ICD10Data C90] |
| C90.01 | Multiple myeloma in remission | Remission-state code. [ICD10Data C90] |
| C90.02 | Multiple myeloma in relapse | Relapse-state code; useful for R/R cohort logic. [ICD10Data C90] |
| C90.10 | Plasma cell leukemia not having achieved remission | Separate high-risk plasma-cell leukemia cohort. [ICD10Data C90] |
| C90.11 | Plasma cell leukemia in remission | Remission state. [ICD10Data C90] |
| C90.12 | Plasma cell leukemia in relapse | Relapse state. [ICD10Data C90] |
| C90.20 | Extramedullary plasmacytoma not having achieved remission | Separate plasmacytoma logic. [ICD10Data C90] |
| C90.21 | Extramedullary plasmacytoma in remission | Remission state. [ICD10Data C90] |
| C90.22 | Extramedullary plasmacytoma in relapse | Relapse state. [ICD10Data C90] |
| C90.30 | Solitary plasmacytoma not having achieved remission | Usually local therapy/surveillance; separate from systemic MM. [ICD10Data C90] |
| C90.31 | Solitary plasmacytoma in remission | Remission state. [ICD10Data C90] |
| C90.32 | Solitary plasmacytoma in relapse | Relapse state. [ICD10Data C90] |
| D47.2 / related MGUS code family | Monoclonal gammopathy | Precursor state; should not define active MM by itself. [FindICD10 MM Coding Guide] |
| Z85.79 | Personal history of other malignant neoplasms of lymphoid, hematopoietic and related tissues | History-only code; should not define active MM. [ICD10Data C90] |

#### 10.1.2 Coding Caveat

C90.0 is non-billable/non-specific and should not be submitted for reimbursement when the remission/relapse-specific codes C90.00, C90.01, or C90.02 are available. MM cohort logic should use remission state, relapse state, treatment exposure, and plasma-cell disorder codes carefully to avoid mixing active MM, smoldering MM, MGUS, solitary plasmacytoma, and plasma cell leukemia. [ICD10Data C90.0], [ICD10Data C90]

#### 10.2.4 Coding Caveat

MM analytics require both medical and pharmacy benefit data. Infused and injected products such as Darzalex Faspro, Sarclisa, Velcade, Kyprolis, Tecvayli, Talvey, Elrexfio, bone agents, and CAR-T procedures are often captured medically, while lenalidomide, pomalidomide, ixazomib, selinexor, venetoclax, and many supportive medications are captured through pharmacy benefit. Medical-only datasets will undercount key MM regimens. [Mordor Multiple Myeloma Market 2026-2031], [J&J Darzalex Billing]
