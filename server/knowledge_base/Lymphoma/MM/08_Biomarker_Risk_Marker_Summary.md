# Multiple Myeloma (MM) — Biomarker / Risk Marker Summary


## 8. Biomarker / Risk Marker Summary

| Marker | Role | Market / Treatment Relevance |
|---|---|---|
| M protein | Disease marker | Diagnosis and response monitoring |
| Serum free light chains | Disease marker | Light-chain disease monitoring and diagnosis |
| Bone marrow plasma-cell percentage | Diagnostic / disease burden | Distinguishes MGUS/SMM/MM and supports response assessment |
| del(17p) / TP53 | High-risk cytogenetic marker | High-risk treatment and maintenance intensification relevance |
| t(4;14) | High-risk cytogenetic marker | PI-containing therapy often important |
| t(14;16) | High-risk cytogenetic marker | High-risk prognosis |
| t(14;20) | High-risk cytogenetic marker | High-risk prognosis |
| gain/amp 1q | High-risk marker | Increasingly important in risk models and trials |
| t(11;14) | Venetoclax-sensitive biology in selected MM | Predicts BCL-2 dependence; venetoclax use is off-label/selected and requires caveat |
| R-ISS / ISS | Risk staging | Prognosis and trial stratification |
| MRD negativity | Depth-of-response marker | Used in trials, response-adapted strategies, payer/outcomes discussions |
| BCMA expression | Target biology | CAR-T, bispecifics, ADCs |
| GPRC5D expression | Target biology | Talquetamab and emerging GPRC5D therapies |
| FcRH5 expression | Target biology | Cevostamab and emerging FcRH5 therapies |
| Renal impairment | Clinical risk marker | Bortezomib-based approaches and dose adjustment relevance |
| Frailty | Treatment-selection marker | Dose modification, transplant ineligibility, supportive care |
