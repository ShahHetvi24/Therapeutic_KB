# Chronic Lymphocytic Leukemia (CLL) — ICD-10, HCPCS/CPT and Drug Code Reference


## 10. ICD-10, HCPCS/CPT and Drug Code Reference


### 10.1 ICD/10 Codes

#### 10.1.1 Core CLL ICD-10-CM Codes

| ICD-10-CM Code | Description | Notes |
|---|---|---|
| C91.1 | Chronic lymphocytic leukemia of B-cell type | Non-billable category code; use specific subcodes |
| C91.10 | Chronic lymphocytic leukemia of B-cell type not having achieved remission | Billable; commonly used for active or NOS CLL |
| C91.11 | Chronic lymphocytic leukemia of B-cell type in remission | Billable remission-state code |
| C91.12 | Chronic lymphocytic leukemia of B-cell type in relapse | Billable relapse-state code |
| C83.0- | Small cell B-cell lymphoma / lymphoplasmacytic lymphoma family | May be relevant for SLL-like or differential lymphoma coding depending documentation |
| Z85.6 | Personal history of leukemia | History-only code; should not define active CLL by itself |

ICD10Data states that C91.1 is non-billable/non-specific and should not be used for reimbursement because more specific subcodes exist; C91.10 is a billable/specific code for CLL of B-cell type not having achieved remission. [ICD10Data C91.1], [ICD10Data C91.10]

#### 10.2.3 Coding Caveat

CLL has a large oral specialty-drug component. Claims-based analytics should combine medical claims, pharmacy claims, specialty pharmacy feeds, and EHR/genomics data where possible. Medical benefit-only datasets will undercount BTK inhibitors, venetoclax, pirtobrutinib, and other oral targeted therapies. [Mordor CLL Drugs Market 2026-2031], [FDA Acalabrutinib + Venetoclax 2026]
