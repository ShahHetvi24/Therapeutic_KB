# Chronic Lymphocytic Leukemia (CLL) — Diagnosis and Clinical Evaluation


## 5. Diagnosis and Clinical Evaluation

| Workup Component | Role |
|---|---|
| CBC with differential | Detects lymphocytosis, anemia, thrombocytopenia |
| Peripheral blood smear | Evaluates morphology and excludes other leukemia/lymphoma patterns |
| Flow cytometry | Confirms clonal B-cell CLL immunophenotype |
| FISH / cytogenetics | Detects del(17p), del(11q), trisomy 12, del(13q), and other abnormalities |
| TP53 mutation testing | Critical predictive and prognostic test before therapy selection |
| IGHV mutation status | Prognostic marker and treatment-selection factor |
| Beta-2 microglobulin | Prognostic marker used in risk models |
| Immunoglobulin levels | Evaluates infection risk and hypogammaglobulinemia |
| CT/PET imaging | Not always required for routine CLL; may be used for bulky disease, transformation assessment, or clinical trial baseline |
| Lymph node biopsy | Important when Richter transformation is suspected |
| Bone marrow biopsy | Not required for all cases; useful for cytopenia evaluation, response documentation, or diagnostic uncertainty |
