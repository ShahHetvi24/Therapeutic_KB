# Non-Hodgkin Lymphoma (NHL) — Diagnosis and Clinical Evaluation


## 5. Diagnosis and Clinical Evaluation

| Workup Component | Role |
|---|---|
| Excisional or core biopsy | Establishes histology; excisional biopsy preferred when feasible for architecture |
| Immunohistochemistry / flow cytometry | Identifies lineage and markers such as CD20, CD19, CD10, BCL2, BCL6, MYC, CD5, CD30, cyclin D1 |
| Cytogenetics / FISH | Detects MYC, BCL2, BCL6, CCND1, and other rearrangements |
| Molecular testing / NGS | Identifies mutations such as EZH2, MYD88, TP53, and others depending subtype |
| PET/CT | Staging and response assessment for FDG-avid lymphomas |
| Bone marrow biopsy | Used selectively depending subtype and staging question |
| CBC / CMP / LDH | Baseline disease burden and organ function assessment |
| Hepatitis B testing | Required before anti-CD20 therapy because of reactivation risk |
| HIV / HCV testing | Relevant for subtype risk and treatment safety |
| Cardiac evaluation | Important before anthracycline-containing therapy |
| CNS risk assessment | Important in high-risk DLBCL and certain extranodal presentations |
