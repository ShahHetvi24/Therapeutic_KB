# Non-Hodgkin Lymphoma (NHL) — Biomarker / Risk Marker Summary


## 8. Biomarker / Risk Marker Summary

| Marker | Disease Context | Relevance |
|---|---|---|
| CD20 | Most B-cell NHL | Rituximab, obinutuzumab, mosunetuzumab, glofitamab, epcoritamab |
| CD19 | B-cell NHL | CAR-T, tafasitamab, loncastuximab |
| CD79b | DLBCL and B-cell NHL | Polatuzumab vedotin target |
| CD30 | PTCL, ALCL, some DLBCL, Hodgkin overlap | Brentuximab vedotin target |
| EZH2 mutation | Follicular lymphoma | Tazemetostat eligibility/enrichment |
| MYC rearrangement | DLBCL/high-grade B-cell lymphoma | Prognostic; double-hit/triple-hit classification |
| BCL2 rearrangement | FL, high-grade B-cell lymphoma | Diagnostic/prognostic; double-hit contexts |
| BCL6 rearrangement | DLBCL/high-grade B-cell lymphoma | Prognostic and classification relevance |
| CCND1 / cyclin D1 | Mantle cell lymphoma | Diagnostic marker |
| SOX11 | Mantle cell lymphoma | Diagnostic/prognostic support |
| TP53 mutation | MCL, DLBCL, transformed lymphoma | High-risk biology; trial relevance |
| MYD88 L265P | Lymphoplasmacytic lymphoma/WM and some DLBCL | Diagnostic/therapeutic relevance |
| Ki-67 | MCL, aggressive NHL | Proliferation and prognosis |
| IPI / FLIPI / MIPI | DLBCL / FL / MCL | Risk stratification and treatment intensity |
| PET Deauville score | FDG-avid lymphoma | Response assessment |
