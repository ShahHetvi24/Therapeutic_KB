# Non-Hodgkin Lymphoma (NHL) — ICD-10, HCPCS/CPT and Drug Code Reference


## 10. ICD-10, HCPCS/CPT and Drug Code Reference


### 10.1 ICD/10 Codes

#### 10.1.1 Common NHL ICD-10-CM Code Families

| ICD-10-CM Family | Description | Notes |
|---|---|---|
| C82.- | Follicular lymphoma | Includes grade and anatomical-site-specific codes; remission subcodes exist for some categories. [ICD10Data C82] |
| C83.- | Non-follicular lymphoma | Includes DLBCL, mantle cell lymphoma, Burkitt lymphoma, and other B-cell NHL subtypes. [ICD10Data C83 / ICD lists] |
| C83.1- | Mantle cell lymphoma | Site-specific subcodes; important MCL cohort family |
| C83.3- | Diffuse large B-cell lymphoma | Important DLBCL cohort family; excludes other specific high-grade categories when separately coded |
| C83.7- | Burkitt lymphoma | Aggressive B-cell NHL; distinct treatment and analytics basket |
| C84.- | Mature T/NK-cell lymphomas | Includes mycosis fungoides, Sezary disease, peripheral T-cell lymphoma categories |
| C85.- | Other specified and unspecified types of NHL | Includes unspecified NHL; use cautiously for granular analytics |
| C85.90 | Non-Hodgkin lymphoma, unspecified, unspecified site | Billable but non-specific; should be replaced with subtype code where possible. [ICD10Data C85.90] |
| C86.- | Other specified types of T/NK-cell lymphoma | Includes extranodal NK/T-cell lymphoma and related entities |
| Z85.72 | Personal history of non-Hodgkin lymphoma | History-only code; do not use to define active NHL without active diagnosis/treatment evidence |

#### 10.1.2 Coding Caveat

NHL coding must capture both histology and anatomic site when possible. For market analytics, unspecified NHL codes should be used only as fallback logic and should be supplemented with pathology, treatment regimen, drug basket, and oncology-specialist context. [ICD10Data C82], [ICD10Data C85.90]

#### 10.2.3 Coding Caveat

NHL contains both medical-benefit infused products and pharmacy-benefit oral products. Medical-only claims will capture rituximab, Polivy, bispecifics, ADCs, chemotherapy, and CAR-T procedures more readily than oral BTK inhibitors, lenalidomide, tazemetostat, and other specialty pharmacy products. Use integrated medical, pharmacy, EHR, pathology, and genomic data where possible. [CMS HCPCS Quarterly Update], [ASTCT CAR-T Coding Guide 2026]
